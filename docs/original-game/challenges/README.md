# Кампания Cell Lab v103: манифесты и субстраты испытаний

ПОЛУЧЕНО ЗАПУСКОМ СКРИПТА scripts/extract_cell_lab_challenges

Дата: **11 ноября 2026**. Источник: `cell_lab_103_android_patched.apk` (Version 103, package `com.saterskog.cell_lab`).

Здесь лежит полное машинное представление кампании оригинала — все 70 испытаний («Challenges»): манифест, строки интерфейса и сериализованный субстрат каждого уровня. Это данные, а не эмуляция; они дополняют [05 — Доказательства](../05-evidence-and-validation.md) точными значениями там, где исследование по скриншотам могло дать только качественную оценку.

## Состав каталога

| Файл | Что это |
| --- | --- |
| `levels.xml` | Дословная копия `assets/levels.xml` — манифест кампании |
| `index.json` | Сводка: манифест + строки + ключевые параметры субстрата по каждому уровню |
| `data/<id>.json` | Полный разбор уровня: условия, настройки среды, клетки с геномами, еда |
| `challenges.md` | Всё то же в человекочитаемом виде (генерируется скриптом) |
| `substrate-format.md` | Побайтовая спецификация формата `.substrate` |

Воспроизведение: `python3 -I scripts/extract_cell_lab_challenges.py <apk> <каталог>` (читает APK напрямую; ресурсы вытаскиваются из `resources.arsc` без apktool).

## Как устроен уровень в оригинале

Уровень = запись манифеста + субстрат. Игрок получает чашку Петри в состоянии из `.substrate`, ограниченный набор инструментов и бюджет постановки клеток. Победа/поражение проверяются каждый кадр по счётчикам живых клеток.

### Условия победы (семантика из декомпилированной проверки `j.a(int, CellWorld)`)

Классы клеток (`Cell.E`): **0** — «клетка уровня», **1** — поставлена игроком (или её потомок), **3** — заражённая виросцитами, **6** — гибрид. Счётчики цветов учитывают только клетки уровня (E=0) по цвету текущего режима.

| Тег | Условие |
| --- | --- |
| `user-cells` / `user-cells-max` | win: count(E=1) ≥ N / lose: > N |
| `level-cells` / `level-cells-min` | win: count(E=0)+count(E=3) ≤ N / ≥ N |
| `total-cells-min` | win: все клетки ≥ N |
| `infected-level-cells` / `-max` | win: count(E=3) ≥ N / ≤ N |
| `hybrid-cells-min` | win: count(E=6) ≥ N |
| `black-level-cells` | win: «чёрных» (E=0, \|R\|+\|G\|+\|B\| < 0.1) ≤ N |
| `red-level-cells` / `-min` | win: «красных» (R>0.65, G<0.35, B<0.35) ≤ N / ≥ N |
| `yellow-level-cells` / `-min` | win: «жёлтых» (R>0.65, G>0.65, B<0.35) ≤ N / ≥ N |
| `win-time` | условие должно непрерывно держаться N часов (таймер сбрасывается при любом нарушении) |
| `max-time` | lose: время симуляции превысило N часов |

Частота тегов в кампании: `user-cells` (49 уровней), `level-cells` (16), `win-time` (15), `level-cells-min` (10), `user-cells-max` (7), `red-level-cells*` (6), остальные — единичные.

### Прочее из манифеста

- **Инструменты** (`tools`): подмножество `cell, move, add, remove, info`; пустой тег = `cell, info`.
- **Бюджет постановки** (`place-cells`, по умолчанию **1**): сколько клеток можно поставить за попытку; превышение — «Scope Lab budget».
- **Лимит удалений** (`remove-max`): сколько клеток можно удалить.
- **`max-<тип>`** (например `max-buoyocyte`): максимум режимов данного типа в геноме игрока.
- **`unlocks`**: названия открываемых клеток/инструментов (текст из ресурсов, уровни идут строго по прогрессии).
- **`feature`**: индекс сервисного флага (0…2), который открывает уровень: 0 ← «Противодействие» (11), 1 ← «Скользкий склон» (16, расширенный редактор генома: жёсткость, приоритет, доля массы, stay alive, зеркалирование), 2 ← «Бутылочное горлышко» (26.6).

Прогрессия разблокировок: Phagocyte → Flagellocyte → Lipocyte → Devorocyte → Keratinocyte → Buoyocyte → Glueocyte, Ciliocyte → Nitrocyte → Virocyte → Secrocyte → Gamete → Neurocyte → Myocyte → Senseocyte, Stereocyte → Stemocyte.

## Данные субстратов

- 65 уникальных `.substrate`-файлов на 70 уровней (часть файлов переиспользуется); версии формата файлов 5…95, версий среды 1…24 и 95 — все ветки чтения воспроизведены, 70/70 разбираются без ошибок.
- Суммарно в стартовых состояниях: **13 186 клеток** (максимум 1330 — «Нарушение баланса») и **40 401 частиц еды** (максимум 3481 — «Пищеварение II»).
- Гены: в файлах сохраняются все заполненные слоты 40-режимного массива. Уровни без начальных клеток часто кладут в клетку-«прототип» стандартную 40-режимную заготовку редактора (M0 Phagocyte, M1 Flagellocyte, …) — на неё ссылаются переходы `child1_mode`/`child2_mode`.
- Стены («Лабиринт», 1107 клеток) — фотоциты, соединённые связями (`links` хранит индексы соседей); структура стены восстановима из `data/22.5.json`.
- В шиппед-файлах gzip-поток клеток/ еды **обрезан** (без завершающего CRC) — игра никогда не читает его до конца; декодер делает так же. Подробности и точный порядок байтов — [substrate-format.md](substrate-format.md).

## Границы

- Человекочитаемые имена параметров среды восстановлены по слайдерам настроек и использованию в `CellWorld`; значения в JSON — ровно то, что хранится в файле.
- Типоспецифичные слоты генома (`outputs`, `type_params`) сохранены как массивы; поиндексная атрибуция под каждый из 18 типов клеток (секреция Secrocyte, smell Senseocyte и т.д.) в эту выгрузку не входила.
- Строки уровня лежат в `res/values/arrays.xml` (`level_strings`, по 4 строки на уровень: имя, описание, подсказка×2); в `index.json` они уже влиты.
