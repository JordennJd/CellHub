# CellHub

Общий PoC объединяет React-редактор многоклеточного генома и Rust/wgpu-отрисовку мира через WebGPU или WebGL2.
Редактор, панели и оформление находятся в React; `crates/frontend` рисует только
мир, а симуляция Rust/hecs работает в Worker. Опционально тот же Rust-мир может
исполняться на авторитарном сервере и транслироваться в публичные комнаты по
WebSocket; редактор генома при этом остаётся локальным у каждого игрока.
Подробности: [гибридная архитектура](docs/rust-frontend.md) и
[сетевой режим](docs/multiplayer.md).

Локальная веб-песочница искусственной жизни: React/TypeScript управляет интерфейсом, Rust/wgpu и WGSL-шейдеры рисуют субстрат и клетки с инстансингом, Rust nightly + hecs ECS исполняет симуляцию в Web Worker через WebAssembly. Один и тот же рендерер работает через WebGPU, а при его недоступности — через WebGL2 (GL-бэкенд wgpu и трансляция WGSL в GLSL).

## Запуск

Нужны Node.js 22.12+ (или 24+), Rustup и закреплённый `rust-toolchain.toml` toolchain. Rustup автоматически установит nightly и цель WASM. Для Nix: `nix develop`.

```sh
npm ci
cargo install wasm-bindgen-cli --version 0.2.130 --locked
npm run build:wasm
npm run build:rust-frontend
npm run dev
```

Открыть адрес Vite (обычно http://127.0.0.1:5173). На этом компьютере Rust и CLI установлены локально в `.tools/`; сборщик поддерживает эту установку, обычный Cargo и явный `CARGO_HOME`. `./start.command` собирает оба WASM-модуля и запускает Vite. Первичная установка зависимостей обязательна; в терминале должен быть активен Node.js 22.12+ (например, `nvm use 22`).

Если установлен [just](https://github.com/casey/just) (он входит в Nix devShell), те же шаги выполняет `just dev`: при необходимости ставит npm-зависимости, автоматически устанавливает `wasm-bindgen-cli` 0.2.130 в `.tools/wasm-bindgen`, собирает WASM и запускает Vite. Без аргументов `just` запускает `just dev`. Список рецептов — `just --list`.

`just install-hooks` включает git-хук, который перед коммитом проверяет форматирование Rust через `cargo fmt --check` и порядок модулей в `crates/` через `just check-order`. Отформатировать код — `just fmt`.

Production-сборка деплоится на тестовый сервер через `just deploy <host> [ssh-port]`. Адрес сервера не хранится в репозитории и передаётся аргументом. Внутри сервера статика раздаётся по HTTP на порту 8081, откуда её забирает внешний reverse-proxy.

```sh
npm run build       # WASM + TypeScript + production bundle в dist/
npm test            # 25 Rust + 6 модели редактора + 3 WASM + сетевой смоук
npm run test:rust   # только Rust-тесты
npm run test:server # публичная комната, чанки и server-authoritative команды
npm run check       # проверка TypeScript (после сборки WASM)
npm run preview     # production-версия после npm run build
```

`dist/` можно раздавать любым статическим HTTP-сервером с MIME `application/wasm`. Web Worker и WASM не загружаются через `file://`. COOP/COEP не требуются: SharedArrayBuffer пока не используется. Canvas рисуется через Rust/wgpu. При загрузке приложение пытается запустить WebGPU; если это не удалось, кнопка WebGPU в шапке блокируется, а рендерер принудительно переключается на WebGL2. Перезагрузка страницы повторяет попытку WebGPU. Две кнопки WebGPU/WebGL позволяют переключать бэкенд вручную; принудительный WebGL также доступен через `?renderer=webgl`. Активный бэкенд доступен в атрибуте `data-renderer` канваса для диагностики. Android поддерживается как адаптивная веб-страница, не APK; на устройстве пока не проверено.

## Как пользоваться

1. Начальный геном состоит из одного слота M1 с типом Фотоцит. Слоты можно добавлять без заданного верхнего лимита, переименовывать, копировать и удалять. Настройте тип клетки, деление, слоты потомков, распределение массы, угол, скорость и срок жизни.
2. На ПК ЛКМ ставит клетку с геномом из редактора, даже если курсор двигается во время клика. Удержание ЛКМ от одной секунды размещает клетки каждые 200 мс в текущей позиции курсора; отпускание кнопки или потеря фокуса останавливает размещение. ПКМ выбирает клетку и загружает её геном. Зажатое колёсико перемещает карту, прокрутка меняет масштаб у курсора. Контекстное меню, автопрокрутка и выделение текста внутри канваса отключены.
3. Сенсорное управление включается автоматически, если устройство поддерживает касания. Слева доступны инструменты размещения, выбора и перемещения. Касание использует выбранный инструмент; перетаскивание перемещает карту. Два пальца одновременно меняют масштаб и перемещают карту. Завершение или отмена жеста не создаёт клетку. За пределами карты страницу и редактор можно прокручивать обычным способом.
4. При достижении порога массы клетка делится на двух потомков. Потомки наследуют весь геном и используют назначенные им слоты. Связь между потомками и наследование связей родителя задаются независимо. «Применить» меняет геном только выбранной клетки; «Наблюдение» показывает её параметры.
5. Доступны пауза, один шаг (1/30 с), скорости 1×/2×/4×, возврат ко всей карте через ⛶ и слои биомов, света, пищи и радиации.
6. «Сохранить» и «Загрузить» работают с геномом редактора, включая имена слотов, в localStorage браузера. Состояние мира не сохраняется. Старые сохранения из восьми режимов поддерживаются.
7. «Режим демонстрации» в начале редактора раскрывает примеры. Загрузка примера заменяет только слоты редактора, оставляя карту и существующих клеток в текущем состоянии.
8. **«Сеть»** открывает необязательный многопользовательский режим. Подключитесь к серверу, создайте публичную комнату или войдите в чужую. Создание комнаты начинает новый сценарий на сервере; сервер исполняет общую сцену и присылает карту последовательными чанками, а клиент предсказывает движение между ними и полностью уступает серверным обновлениям. Геном редактора не синхронизируется — у каждого игрока он свой. Запуск: `just server` (см. [docs/multiplayer.md](docs/multiplayer.md)).

Пример многоклеточного организма: M1-фотоцит → связанные M2-жгутикоцит и M3-фагоцит. M2 не делится; M3 порождает M3 с прежними связями и отдельный M1. После загрузки поместите M1 на светлом участке. Подробнее: [геном и адгезия](docs/multicellular-genome.md).

## Реализованные механизмы

- Карта 3072 × 3072, 48 × 48 ресурсных участков, четыре hardcoded-биома. Участки хранят свет, радиацию и истощаемую/восстанавливаемую пищу.
- Шесть типов: Photocyte (свет), Phagocyte (пища), Flagellocyte (движение), Virocyte (контактное копирование генома), Keratinocyte (пониженный метаболизм и защита от хищника), Devorocyte (поглощение массы соседа).
- Движение, простое разделение пересекающихся клеток, обмен веществ, деление, старение, голодание, мутации в радиационной зоне, заражение. Пространственная сетка ограничивает поиск соседей.
- До 20 000 живых клеток. При лимите деление откладывается; попытка нового размещения возвращает ошибку. Это защитный лимит, не гарантия 30 Hz на любом устройстве. Проверены загрузка 20 000 клеток и один шаг в браузере; устойчивый FPS при такой популяции не гарантируется. `?count=20000&paused` создаёт равномерную сетку внутри карты.

Типы вдохновлены [Cell Lab Types](https://cell-lab.fandom.com/wiki/Types), но биофизика и баланс — упрощённая собственная модель. **Это первый рабочий вертикальный срез, не полная копия CellLab.** Остальные 12 типов, мышцы/нейронные сигналы, полноценное сохранение мира, GPU compute и SharedArrayBuffer ещё не реализованы. Сетевой режим реализован как опциональный server-authoritative PoC: публичные комнаты, WebSocket, последовательные чанки и клиентское предсказание.

## Структура и границы

- `crates/simulation/src/`: `genome.rs` (архетипы и ABI генома), `terrain.rs` (карта), `components.rs` (ECS-компоненты), `simulation/` (WASM API, fixed-step системы, пространственная сетка, связи и тесты). Rust не зависит от DOM или React; тот же крейт исполняется нативным сервером.
- `crates/protocol/`: общий контракт JSON-команд и бинарного формата чанков.
- `crates/server/`: авторитарный сервер на axum/tokio, публичные комнаты, WebSocket и раздача `dist/`.
- `frontend/simulation.worker.ts`: локальный режим — очередь команд, загрузка WASM, часы и перенос снимков на главный поток.
- `frontend/net/`: WebSocket-клиент, бинарный протокол и предсказанная сцена для сетевого режима; `OnlinePanel.tsx` — лобби и публичные комнаты.
- `frontend/model.ts`: контракт команд и представление генома в UI.
- `frontend/WorldView.tsx`: выбор бэкенда, повторный монтаж при сбое и принудительный переход на WebGL. `frontend/backend.ts`: начальный выбор WebGPU и тип бэкенда. `frontend/RendererToggle.tsx`: две кнопки WebGPU/WebGL с блокировкой WebGPU после ошибки. `RustWorldView.tsx`: камера, hit testing и отрисовка; биология остаётся в Worker.
- `crates/frontend/src/web/`: прямой wgpu-рендерер (`backend.rs`, `labels.rs`, `gpu.rs`, `renderer.rs`, `repaint.rs`, `mod.rs`), GPU-буферы, resize и освобождение ресурсов. `scene_data.rs`: подготовка инстансов связей и native-тесты.
- `crates/frontend/src/scene.wgsl`: инстансинг клеток и связей, SDF-оформление, карта и подписи. egui/eframe не используются.
- `frontend/main.tsx`: HTML/React-редактор и управление экспериментом.
- `docs/architecture.md`: ABI, порядок систем и ограничения; `docs/multiplayer.md`: протокол, чанки и предсказание.

Исходная C++/Emscripten-заготовка (`CMakeLists.txt`, `src/main.cpp`, `web/shell.html`, `scripts/build.sh`) сохранена как legacy и не участвует в новом запуске.
