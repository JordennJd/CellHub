# Цветовая гамма CellHub

Источник — версия `a1cb8ae` (`feat: server`): `frontend/style.css`, `crates/frontend/src/scene.wgsl` и фон очистки в `crates/frontend/src/web/renderer.rs`.

Палитра перенесена на актуальную `main` (`7d1479f`). Сохранены начальный экран, обучение, испытания, песочница, Арена с лобби, библиотеки и редактор. Перенос затрагивает цвета и прозрачность: шрифты, размеры, расположение, геометрия чашки и игровая логика остаются актуальными.

Типовые цвета клеток уже совпадали с исходной версией. Собственный RGB сохраняется, тело использует прозрачность 0,22. Контур и ядро обычно используют цвет клетки; для слишком тёмных пользовательских цветов они становятся светлыми (`#dce6dc`), чтобы клетка оставалась видимой. Порог относительной яркости 0,22038945 соответствует контрасту 3:1 с фоном чашки. Предпросмотр оформлен аналогично. Вместо восстановления старой квадратной карты с четырьмя биомами текущая круглая чашка получает один прежний зелёный фон; её маска, масштаб и условия симуляции не меняются.

## Читаемость

Основные непрозрачные пары проверены расчётом контраста: основной текст на фоне — 14,24:1; вторичный текст на панели — 7,11:1; подпись основного действия — 10,61:1; выбранный элемент — 7,54:1; текст ошибки — 5,33:1. Поля используют усиленную границу (3,83:1 относительно их фона). При наведении основная кнопка сохраняет светлый фон и тёмный текст. Для нативных контролов задан `color-scheme: dark`, цвет браузерной панели соответствует фону приложения.

Это проверка перечисленных цветовых пар, а не заявление о полном аудите доступности приложения.
