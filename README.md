# CellHub

Главная страница использует прежний React-интерфейс и Rust/WebGPU для canvas.
Редактор, панели и оформление находятся в React; `crates/frontend` рисует только
мир, а симуляция Rust/hecs работает в Worker. Подробности: [гибридная архитектура](docs/rust-frontend.md).

Локальная веб-песочница искусственной жизни: React/TypeScript управляет интерфейсом, Rust/wgpu и WGSL-шейдеры рисуют субстрат и клетки через WebGPU с инстансингом, Rust nightly + hecs ECS исполняет симуляцию в Web Worker через WebAssembly.

## Запуск

Нужны Node.js 22.12+ (или 24+), Rustup и закреплённый `rust-toolchain.toml` toolchain. Rustup автоматически установит nightly и цель WASM. Для Nix: `nix develop`.

```sh
npm ci
cargo install wasm-bindgen-cli --version 0.2.130 --locked
npm run build:wasm
npm run build:rust-frontend
npm run dev
```

Открыть адрес Vite (обычно http://127.0.0.1:5173). На этом компьютере Rust и CLI также установлены локально в `.tools/`; сборочные скрипты используют их, если Cargo отсутствует в PATH. `./start.command` собирает WASM и запускает Vite. Первичная установка зависимостей обязательна.

Если установлен [just](https://github.com/casey/just) (он входит в Nix devShell), те же шаги выполняет `just dev`: при необходимости ставит npm-зависимости, автоматически устанавливает `wasm-bindgen-cli` 0.2.130 в `.tools/wasm-bindgen`, собирает WASM и запускает Vite. Без аргументов `just` запускает `just dev`. Список рецептов — `just --list`.

Production-сборка деплоится на тестовый сервер через `just deploy <host> [ssh-port]`. Адрес сервера не хранится в репозитории и передаётся аргументом. Внутри сервера статика раздаётся по HTTP на порту 8081, откуда её забирает внешний reverse-proxy.

```sh
npm run build       # WASM + TypeScript + production bundle в dist/
npm test            # 8 native Rust + 2 проверки настоящего WASM
npm run test:rust   # только тесты модели
npm run check       # проверка TypeScript (после сборки WASM)
npm run preview     # production-версия после npm run build
```

`dist/` можно раздавать любым статическим HTTP-сервером с MIME `application/wasm`. Web Worker и WASM не загружаются через `file://`. COOP/COEP не требуются: SharedArrayBuffer пока не используется. Canvas рисуется через Rust/wgpu/WebGPU; необходимы secure context и поддержка браузером. Android поддерживается как адаптивная веб-страница, не APK; на устройстве пока не проверено.

## Как пользоваться

1. Выберите режим 1–8 и тип клетки в редакторе. Настройте порог деления, режимы двух дочерних клеток, долю массы, угол, скорость и срок жизни.
2. Инструмент «Поместить»: клик по карте создаёт клетку с полным геномом из редактора. «Начать с примера» создаёт 60 клеток шести типов.
3. Масса растёт от света или пищи. При достижении порога родитель заменяется двумя потомками. Они наследуют весь геном, но используют назначенные им режимы. Масса делится в заданной пропорции.
4. Инструмент «Выбрать»: клик по клетке загружает её геном в редактор. Кнопка «Применить» меняет только эту клетку; вкладка «Наблюдение» показывает её массу, возраст, поколение и изменения генома. После деления выберите потомка заново.
5. Пауза, один шаг (1/30 с), скорости 1×/2×/4×. Перетаскивание перемещает камеру, колесо масштабирует, ⛶ показывает весь субстрат. На сенсорном экране доступны размещение/выбор касанием и перемещение перетаскиванием.
6. Переключайте биомы/свет/пищу/радиацию. Сохранение и загрузка сохраняют **геном редактора**, а не весь мир, в localStorage браузера.

## Реализованные механизмы

- Карта 3072 × 3072, 48 × 48 ресурсных участков, четыре hardcoded-биома. Участки хранят свет, радиацию и истощаемую/восстанавливаемую пищу.
- Шесть типов: Photocyte (свет), Phagocyte (пища), Flagellocyte (движение), Virocyte (контактное копирование генома), Keratinocyte (пониженный метаболизм и защита от хищника), Devorocyte (поглощение массы соседа).
- Движение, простое разделение пересекающихся клеток, обмен веществ, деление, старение, голодание, мутации в радиационной зоне, заражение. Пространственная сетка ограничивает поиск соседей.
- До 20 000 живых клеток. При лимите деление откладывается; попытка нового размещения возвращает ошибку. Это защитный лимит, не гарантия 30 Hz на любом устройстве. Нагрузочная проверка нового лимита не проводилась.

Типы вдохновлены [Cell Lab Types](https://cell-lab.fandom.com/wiki/Types), но биофизика и баланс — упрощённая собственная модель. **Это первый рабочий вертикальный срез, не полная копия CellLab.** Остальные 12 типов, связи/мышцы/нейронные сигналы, полноценное сохранение мира, сетевой режим, GPU compute и SharedArrayBuffer ещё не реализованы.

## Структура и границы

- `crates/simulation/src/lib.rs`: данные ECS, генерация карты, fixed-step системы, WASM API и тесты. Rust не зависит от DOM, React или PixiJS.
- `frontend/simulation.worker.ts`: очередь команд, загрузка WASM, часы и перенос снимков на главный поток.
- `frontend/model.ts`: контракт команд и представление генома в UI.
- `frontend/WorldView.tsx`: камера, hit testing, передача снимков и параметров в Rust-renderer. Не рассчитывает биологию.
- `crates/frontend/src/lib.rs`: прямой wgpu-рендерер, GPU-буферы, resize и освобождение ресурсов; редактор находится в React.
- `crates/frontend/src/scene.wgsl`: инстансинг клеток, SDF-оформление, карта и подписи. egui/eframe не используются.
- `frontend/main.tsx`: HTML/React-редактор и управление экспериментом.
- `docs/architecture.md`: ABI, порядок систем, сетевое расширение и ограничения.

Исходная C++/Emscripten-заготовка (`CMakeLists.txt`, `src/main.cpp`, `web/shell.html`, `scripts/build.sh`) сохранена как legacy и не участвует в новом запуске.
