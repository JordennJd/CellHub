# Многоклеточный геном

Геном содержит от 1 до 40 архетипов M1…M40. У каждого свой тип клетки, параметры жизненного цикла, два архетипа потомков и три независимых правила адгезии. Потомки получают копии всего генома и активируют указанные архетипы. Циклы, например M1 → M3 → M1, разрешены.

## Настройки деления

| Настройка | Действие |
|---|---|
| Разрешить деление | Выключение полностью запрещает деление независимо от массы; питание, движение и старение продолжаются |
| Дочерняя клетка A / B | Архетип каждого потомка |
| Связать A и B после деления | Создаёт новую механическую связь между потомками |
| A может унаследовать связи родителя | A участвует в выборе нового конца для каждой прежней связи |
| B может унаследовать связи родителя | B участвует в выборе нового конца для каждой прежней связи |
| Распределение массы | Доля A и B от массы родителя на момент деления |
| Угол деления | Направление размещения потомков относительно ориентации родителя |

Флаги принадлежат **делящемуся архетипу**. Настройки A и B применяются при этом делении, а настройки активируемых архетипов — при последующих делениях потомков. Включённый флаг разрешает наследование. Дочь получает прежнюю связь, если после размещения она находится в зоне контакта с соседом и сестра этот контакт не перекрывает. Если сосед тоже делится, проверяются положения его дочерей. Связь исчезает, если подходящих клеток нет. Связь A–B создаётся отдельно.

Если обе связанные дочери могут сохранить по одному контакту с прежними соседями, движок предпочитает такое распределение. Это помогает цепочке или кольцу остаться непрерывными. Когда обе дочери подходят для одной прежней связи, возможны два контакта без перекрещивания. Вместе со связями между дочерьми они могут замкнуть контур. Новые связи с посторонними клетками при наследовании не возникают.

Угол влияет на результат через расположение дочерей. В симметричном примере четыре клетки при 0° образуют прямую цепочку. При 90° из четырёх клеток получается квадрат, который после следующего деления становится кольцом из восьми клеток.

Если в цикле дочерняя B продолжает тот же архетип, что и родитель, поворот B на 180° сохраняет её прежнее направление. Без него следующее деление разворачивает ось внутрь организма, дочь-семя перекрывает унаследованную связь, и цепочка распадается.

Удаление или гибель клетки убирает её связи. Редактирование генома живой клетки задаёт правила будущего деления и сохраняет существующие связи.

## Пример из задачи

| Архетип | Тип | Деление | Потомки | Связать A–B | A может наследовать | B может наследовать |
|---|---|---|---|---|---|---|
| M1 | Фотоцит | Да | A=M2, B=M3 | Да | Нет | Нет |
| M2 | Жгутикоцит | Нет | Не используются | Нет | Нет | Нет |
| M3 | Фагоцит | Да | A=M1, B=M3 | Нет | Нет | Да |

1. Открыть редактор генома: раздел «Готовые организмы» доступен там постоянно. Ниже встроенного каталога показываются сохранённые геномы пользователя.
2. Поместить M1 на светлом участке субстрата; для быстрого наблюдения выбрать 4×.
3. При достижении массы 2 нг M1 создаёт связанные M2 и M3. Жгутик M2 перемещает пару.
4. При достижении массы 2,4 нг M3 создаёт дочернюю клетку B в режиме M3 рядом с M2. Она сохраняет прежнюю связь. Дочь B развёрнута на 180° и поэтому продолжает смотреть от колонии: следующее деление снова выносит семя A наружу, а B оставляет у связи. Дочь A в режиме M1 остаётся свободной.
5. M1 запускает следующий цикл. M2 продолжает жить без деления.

Связи видны линиями на карте. В «Наблюдении» есть общее число связей и число связей выбранной клетки. После деления родитель исчезает: для просмотра генома нужно выбрать одного из потомков.

## Каталог демонстрационных организмов

Раздел «Готовые организмы» в редакторе генома доступен во всех режимах игры и предлагает готовые многоклеточные конструкции. Этот же каталог используется «Хаосом» для самозарождения: поле `span` задаёт длину стартовой цепочки.

| Организм | Роли | Стартовая цепочка |
|---|---|---:|
| Фотоцитовая нить | фотоцит с удержанием обеих дочерей | 2 |
| Учебная тройка | фотоцит + жгутикоцит + фагоцит | 3 |
| Умный фагоцит | фотоцит-семя + фагоцит + миоцит + сенсоцит + жгутикоцит | 5 |
| Мох | фотоцит + глюоцит | 2 |
| Хищник | фагоцит + жгутикоцит | 2 |
| Нанобот | фотоцит + глюоцит + кератиноцит | 3 |
| Умный хищник | девороцит + кератиноцит + миоцит + сенсоцит + жгутикоцит | 5 |

Сложные конструкции собраны композицией простых ролей. «Умный фагоцит» и «умный хищник» используют сенсоцит как источник сигнала, миоцит для поворота тела и жгутикоцит для тяги; хищник дополнительно несёт кератиновый щит, чтобы девороцит не высасывал собственных связанных соседей. Умному фагоциту фотоцит-семя даёт возобновляемую энергию, иначе одиночная клетка голодает раньше, чем успевает вырастить жгутик. «Умный хищник» живёт за счёт добычи: в чашке без возобновляемой пищи он вымирает после того, как истощит своё пищевое пятно, и для долгой жизни ему нужны новые жертвы. Если стартовая цепочка длиннее генома, последний режим повторяется.

Проверить весь каталог в реальной симуляции можно так:

```sh
node scripts/check-organisms.mjs /tmp/catalog.json
cargo run -p cellhub-simulation --example organism_check -- /tmp/catalog.json 180 42,73421,91
```

Второй аргумент примера задаёт длительность в секундах, третий — необязательный список seed'ов.

Ниже встроенного каталога показываются сохранённые геномы из библиотеки. Если в испытании разрешены не все типы клеток, несовместимые конструкции не предлагаются или показываются недоступными.

## Редактор и сохранения

Можно добавлять, копировать и удалять архетипы; хотя бы один всегда остаётся. При копировании ссылки архетипа на самого себя направляются на копию. При удалении ссылки перенумеровываются; ссылки непосредственно на удалённый архетип переходят к следующему (для последнего — к предыдущему). Интерфейс сообщает об этом действии.

Сохранение/загрузка сохраняет полный геном в браузере, включая запрет деления и все три флага адгезии. Старые сохранения из восьми режимов автоматически получают разрешённое деление и выключенную адгезию. При размещении используется отдельно выбранный начальный режим; выбор режима для редактирования его не меняет. Доступны независимые направления дочерей, зеркальность и собственный RGB-цвет. Геном и мир сохраняются раздельно в именованной библиотеке.

## Механика и границы реализации

Связи удерживают клетки вместе и передают движение жгутика. Их длина зависит от радиусов клеток и сокращения миоцита. Связанные клетки обмениваются массой, азотом, токсином и сигналами S1–S8. Липоцит блокирует передачу сигналов через себя. Приоритет питания определяет распределение массы. Порог связей ограничивает деление, а у глюоцита также ограничивает число связей, которые он создаёт.

Контракт данных и порядок шага описаны в [architecture.md](architecture.md). Проверки охватывают восемь сочетаний адгезии, одновременное деление соседей, цикл M1/M2/M3, движение связанной пары, смерть/reset, цепочку у границы, 40 архетипов, сериализацию и миграцию старых сохранений.
