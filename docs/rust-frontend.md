# Гибридный фронтенд

Главная страница — исходный React-интерфейс с исходным CSS. Сохранены редактор восьми режимов, шесть типов клеток и их описания, все параметры деления, потомки, распределение масс, угол, движение и срок жизни, сохранение/загрузка/сброс генома, изменение выбранной клетки, наблюдение и статистика, пример на 60 клеток, пауза/шаг/скорости, очистка, выбор/размещение/перемещение, масштаб и центрирование, легенда, слои, сообщения и пустое состояние.

Симуляция работает в прежнем Worker. `WorldView.tsx` управляет камерой и событиями указателя, передаёт последний снимок и параметры в `WorldRenderer`. Canvas рисуется напрямую через Rust/wgpu/WebGPU; egui/eframe удалены. Сохранены биомы и слои света/радиации/пищи, частицы пищи, граница и подписи карты, ореол/оболочка/ядро клетки, жгутик, маркер мутации и выделение.

На кадр выполняются три draw call: карта одним полноэкранным проходом, четыре подписи одним instanced draw и все клетки одним instanced draw. Общий квадрат задаётся через vertex_index. Каждая клетка — 40 байт исходного snapshot в instance buffer; CPU не строит окружности/треугольники и не упаковывает отдельные вершины. Vertex shader применяет камеру, fragment shader вычисляет форму/сглаживание и оформление через расстояния (SDF). Невидимая геометрия отсекается графическим конвейером; CPU-culling и GPU compute simulation здесь отсутствуют.

Буфер клеток переиспользуется и растёт геометрически по необходимости; terrain — постоянный storage buffer. Подписи один раз растеризуются в atlas через offscreen Canvas2D, затем выводятся WebGPU. Снимки отправляются только при изменении; кадр рисуется при изменении данных/камеры или resize. Копирование через wasm-bindgen и загрузка в GPU остаются, zero-copy не заявляется.

В Rust нет редактора и второй симуляции. При размонтировании React останавливает renderer и удаляет обработчики. Сохранённые геномы исходного интерфейса доступны через прежний ключ `cellhub.genome.v1`.

Нужны браузер с WebGPU и localhost или HTTPS. JS-загрузчик и ABI остаются необходимой частью WASM-интеграции. Шрифт и растеризация canvas могут незначительно отличаться от Pixi; React-разметка и CSS сохранены.

Запуск из корня проекта:

```powershell
npm run build:wasm
npm run build:rust-frontend
npm run dev
```

Production: `npm run build`, затем `npm run preview`.
WASM-bindgen заново генерирует `frontend/rust-wasm` с экспортом `WorldRenderer`; старые сгенерированные файлы после предыдущей версии нужно пересобрать указанной командой.

Проверены production-сборка и короткий браузерный сценарий на 60 клетках: запуск, слои, размещение/выбор, применение генома, сохранение/загрузка, наблюдение, пауза/шаг, zoom, центрирование и узкий экран. Лимит модели и UI увеличен до 20 000; нагрузочный тест и сравнение FPS не выполнялись. Результаты прошлой полностью Rust-версии сюда не переносятся. Для дальнейшего профилирования отдельно измерять simulation.advance в Worker, получение/перенос snapshot, CPU submit рендерера и GPU/frame time; время queue.submit не является временем GPU.
